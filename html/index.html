🌐 Webserv — Test Suite

Page d'accueil du site de test. Utilise les liens ci-dessous pour valider chaque fonctionnalité du serveur.

📄 Fichiers statiques

  • index.html GET — cette page
  • static.html GET — page statique simple
  • image.html GET — page avec une image

📤 Upload de fichiers

  • upload.html POST — formulaire d'upload

🗑️ Suppression

  • delete.html DELETE — tester la suppression d'un fichier uploadé

⚙️ CGI

  • cgi-bin/hello.py CGI Python — réponse simple
  • cgi-bin/form.py CGI Python — formulaire POST
  • cgi-bin/info.php CGI PHP — phpinfo allégé

❌ Pages d'erreur

  • Lien cassé 404 — déclenche une 404
  • /errors/404.html — page 404 directe
  • /errors/405.html — page 405 directe
  • /errors/500.html — page 500 directe
